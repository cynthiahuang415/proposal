# 黃聿瑄｜個人作品集

獨立 HTML、CSS、JavaScript 網站，包含作品介紹、PDF 與影片，不需建置。

## 本機查看
開啟 index.html，並保留 assets、style.css、app.js 的相對位置。

## GitHub Pages
將本資料夾內所有檔案上傳到 GitHub 儲存庫根目錄。
進入 Settings → Pages，選擇 Deploy from a branch，分支 main，資料夾 / (root)，按 Save。
網站的正式網址以 GitHub Pages 設定頁面顯示的網址為準。

## 修改
- index.html：首頁、個人簡介與聯絡方式
- app.js：作品資料與互動
- style.css：外觀與響應式版面
- assets：作品文件、圖片、影片
